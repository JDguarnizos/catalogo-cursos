¿Qué es una SPA y cómo se que esta app lo es??

Una Simgle Page Application descarga un solo archivo HTML (index.html). Después, Angular cambia partes de la pantalla sin recargar la página.

Experimento con DevTools

  1. Presiona F12 -> pestaña Netork / Red -> Filtro Doc
  2. Navega con el menú entre "Catálogo" y "¿Qué es una SPA?"
  3. No aparece ningún documento nuevo y la hora "App cargada a las..." no cambia.
  4. Presiona F5: ahora si se recarga todo y la hora cambia.
